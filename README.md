# Blog with the Windows XP aesthetic (WIP)

I've gotten really inspired by seeing other people's blogs (Like [Nor's](https://scratch.mit.edu/projects/1146158457) one!) and wanted to try it out doing my own, but with the Windows XP aesthetic.
I used [Lucas Melo's](https://github.com/lucasgmelo/xp) project as a reference for the "login" page, it has a great work and you should give it a look!

## About it

The idea is to use the 2000's era style and using it on the pages, with interactive stuff, like you are using a computer. It's currently made on just HTML, CSS and Java.
